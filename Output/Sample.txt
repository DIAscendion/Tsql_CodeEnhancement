#### 2.2 Transformation Stored Procedure
Create or update a transformation stored procedure to standardize source records and derive reusable business attributes.

Recommended object:
- `etl.usp_Load_FactTileEngagement`

Core logic:
- Deduplicate by `event_id`
- Normalize event type values
- Join tile metadata by `tile_id`
- Derive event date key from `event_ts`
- Map boolean flags to integer indicators where target model requires numeric flags

Example T-SQL snippet:
```sql
;WITH HomeEvents AS
(
    SELECT
        h.EventId,
        h.UserId,
        h.SessionId,
        h.EventTs,
        CAST(h.EventTs AS date) AS EventDate,
        h.TileId,
        UPPER(LTRIM(RTRIM(h.EventType))) AS EventType,
        h.DeviceType,
        h.AppVersion,
        ROW_NUMBER() OVER (PARTITION BY h.EventId ORDER BY h.EventTs DESC) AS rn
    FROM stg.SourceHomeTileEvents h
),
FilteredHomeEvents AS
(
    SELECT *
    FROM HomeEvents
    WHERE rn = 1
)
SELECT
    fhe.EventId,
    fhe.UserId,
    fhe.SessionId,
    fhe.EventTs,
    CONVERT(int, CONVERT(char(8), fhe.EventDate, 112)) AS EventDateKey,
    fhe.TileId,
    tm.TileName,
    tm.TileCategory,
    CASE
        WHEN fhe.EventType = 'TILE_VIEW' THEN 1
        ELSE 0
    END AS TileViewCount,
    CASE
        WHEN fhe.EventType = 'TILE_CLICK' THEN 1
        ELSE 0
    END AS TileClickCount,
    fhe.DeviceType,
    fhe.AppVersion
FROM FilteredHomeEvents fhe
LEFT JOIN stg.SourceTileMetadata tm
    ON fhe.TileId = tm.TileId;
```

#### 2.4 Interstitial Event Processing
Create processing logic for interstitial events, either as a separate fact table or as additional measures in the same engagement fact if the target reporting model is consolidated.

Recommended object:
- `etl.usp_Load_FactInterstitialEngagement`

Business logic:
- `interstitial_view_flag` -> interstitial impression count
- `primary_button_click_flag` -> primary CTA click count
- `secondary_button_click_flag` -> secondary CTA click count
- Enrich by `tile_id` using tile metadata

Example transformation snippet:
```sql
SELECT
    i.EventId,
    i.UserId,
    i.SessionId,
    i.EventTs,
    CONVERT(int, CONVERT(char(8), CAST(i.EventTs AS date), 112)) AS EventDateKey,
    i.TileId,
    tm.TileName,
    tm.TileCategory,
    CASE WHEN ISNULL(i.InterstitialViewFlag, 0) = 1 THEN 1 ELSE 0 END AS InterstitialViewCount,
    CASE WHEN ISNULL(i.PrimaryButtonClickFlag, 0) = 1 THEN 1 ELSE 0 END AS PrimaryButtonClickCount,
    CASE WHEN ISNULL(i.SecondaryButtonClickFlag, 0) = 1 THEN 1 ELSE 0 END AS SecondaryButtonClickCount
FROM stg.SourceInterstitialEvents i
LEFT JOIN stg.SourceTileMetadata tm
    ON i.TileId = tm.TileId;
```

### 4. Data Quality and Constraint Rules
- `event_id` must be unique per source table.
- `tile_id` should match a record in `SOURCE_TILE_METADATA`; unmatched records should be allowed but logged.

- Boolean flags should default to `0` when null in the target measures.

### 5. Consolidated Transformation Logic
```sql
SELECT
    src.EventId,
    src.UserId,
    src.SessionId,
    src.EventTs,
    CONVERT(INT, CONVERT(CHAR(8), CAST(src.EventTs AS DATE), 112)) AS EventDateKey,
    src.TileId,
    dim.TileKey,
    tm.TileName,
    tm.TileCategory,
    src.DeviceType,
    src.AppVersion,
    src.TileViewCount,
    src.TileClickCount,
    src.InterstitialViewCount,
    src.PrimaryButtonClickCount,
    src.SecondaryButtonClickCount
FROM
(
    SELECT
        LTRIM(RTRIM(event_id)) AS EventId,
        NULLIF(LTRIM(RTRIM(user_id)), '') AS UserId,
        NULLIF(LTRIM(RTRIM(session_id)), '') AS SessionId,
        CAST(event_ts AS DATETIME2(3)) AS EventTs,
        LTRIM(RTRIM(tile_id)) AS TileId,
        NULLIF(LTRIM(RTRIM(device_type)), '') AS DeviceType,
        NULLIF(LTRIM(RTRIM(app_version)), '') AS AppVersion,
        CASE WHEN UPPER(LTRIM(RTRIM(event_type))) = 'TILE_VIEW' THEN 1 ELSE 0 END AS TileViewCount,
        CASE WHEN UPPER(LTRIM(RTRIM(event_type))) = 'TILE_CLICK' THEN 1 ELSE 0 END AS TileClickCount,
        0 AS InterstitialViewCount,
        0 AS PrimaryButtonClickCount,
        0 AS SecondaryButtonClickCount
    FROM stg.SourceHomeTileEvents

    UNION ALL

    SELECT
        LTRIM(RTRIM(event_id)) AS EventId,
        NULLIF(LTRIM(RTRIM(user_id)), '') AS UserId,
        NULLIF(LTRIM(RTRIM(session_id)), '') AS SessionId,
        CAST(event_ts AS DATETIME2(3)) AS EventTs,
        LTRIM(RTRIM(tile_id)) AS TileId,
        NULL AS DeviceType,
        NULL AS AppVersion,
        0 AS TileViewCount,
        0 AS TileClickCount,
        CASE WHEN ISNULL(interstitial_view_flag, 0) = 1 THEN 1 ELSE 0 END AS InterstitialViewCount,
        CASE WHEN ISNULL(primary_button_click_flag, 0) = 1 THEN 1 ELSE 0 END AS PrimaryButtonClickCount,
        CASE WHEN ISNULL(secondary_button_click_flag, 0) = 1 THEN 1 ELSE 0 END AS SecondaryButtonClickCount
    FROM stg.SourceInterstitialEvents
) src
LEFT JOIN dbo.DimTile dim
    ON src.TileId = dim.TileId
   AND dim.IsCurrent = 1
LEFT JOIN stg.SourceTileMetadata tm
    ON src.TileId = tm.TileId;
```

## Assumptions and Constraints

- Existing source and target data model documents were not separately available; proposals are based on the supplied DDL files.
- The downstream warehouse supports SQL Server-style T-SQL for transformation and serving layers.
- `event_id` is unique and stable for merge/upsert logic.

- Null or unknown tile metadata should not block fact ingestion, but should be logged for stewardship.

- Ensure least-privilege access for staging and target schemas.
- Add audit logging for load traceability and reconciliation.
- Maintain retention and partition strategy on `EventTs` / `EventDateKey` for performance.
